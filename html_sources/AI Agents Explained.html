CHATBOT VS AGENT

What’s the difference?

💬
ChatbotTells you: “try changing line 12…”
🤖
AI AgentOpens the file, fixes line 12, runs the tests
A chatbot talks.
An agent does things.
ANATOMY

4 parts of an agent

🧠
01 BRAINAn LLMReads the goal and reasons about what to do
🛠️
02 TOOLSHandsSearch, run code, call APIs, edit files
📝
03 MEMORYContextRemembers what it already tried
🔁
04 LOOPPersistenceKeeps going until the goal is met
Brain + tools + memory,
on repeat.
THE LOOP

It runs on a loop

🧠 Think
🛠️ Act
👀 Observe
Think: decide the next step
Act: use a tool
Observe: check what happened
Not done yet? Go again.
LIVE EXAMPLE

Task: fix a failing test

● ● ● agent.log
goal make the tests pass
🧠 think run the tests first
🛠️ act npm test
👀 observe ❌ sum() returns NaN
🧠 think bug is in utils.js:12
🛠️ act edit utils.js
🛠️ act npm test
👀 observe ✅ 12 passed
✔ done pull request ready
